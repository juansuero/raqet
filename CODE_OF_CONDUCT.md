# Code Of Conduct

Raqet is a small open-source project. Keep discussion focused, respectful, and useful.

Expected behavior:

- Be specific when reporting bugs.
- Critique code and product behavior, not people.
- Keep issues and pull requests on topic.
- Do not post secrets, private exports, private videos, or another person's personal data.

Unacceptable behavior:

- Harassment, threats, or personal attacks.
- Spam or repeated off-topic promotion.
- Public disclosure of security vulnerabilities before maintainers have had time to respond.

Maintainers may edit, hide, lock, or delete comments that violate these expectations.
